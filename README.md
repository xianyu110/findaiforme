## 欢迎提交你的 AI 工具 / Submit your tool

我们欢迎开发者、创始人和爱好者提交 AI 工具，让更多人发现它们。

### 方式一：网站表单（推荐）

打开 **[https://findaifor.me/submit](https://findaifor.me/submit)**，填写工具名称、官网、简介、分类与定价信息后提交。审核通过后会出现在目录中。

### 方式二：GitHub Issue / PR

1. 在本仓库开一个 [Issue](https://github.com/xianyu110/findaiforme/issues/new)，标题建议：`[Submit] Your Tool Name`
2. 在正文里写清：
   - 工具名称
   - 官网 URL
   - 一句话简介（中/英均可）
   - 分类（见上表）
   - 定价：`free` / `freemium` / `paid`
3. 也可以直接 PR：在对应分类的 `tools/*.md` 中按现有表格格式追加一行，并在 PR 描述里附上官网链接便于核对。

提交即表示你确认对该工具有权推广，且内容真实、无恶意。

### 收录标准 / Acceptance

**接收 ✓** AI 原生工具 · AI 增强型 SaaS · AI 基础设施 · 任何含 AI 功能的工具  

**不接收 ✗** 无 AI 的传统 SaaS · 电商 / 游戏 / 内容博客 · 静态营销页  

详见提交页：[findaifor.me/submit](https://findaifor.me/submit)。
